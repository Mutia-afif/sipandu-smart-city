Status: 100% Terpenuhi
1. Privasi Warga (Bebas NIK)

Sesuai UU PDP & PRD FR-01, sistem sama sekali tidak meminta, memproses, atau menyimpan NIK pada registrasi warga.

2. Spasial PostGIS 50 Meter

Deteksi duplikasi aduan murni menggunakan fungsi spasial ST_DWithin radius 50m dan pengurutan petugas via ST_Distance.

3. Optimistic Concurrency Control

Setiap transaksi status aduan menguji kolom version INT untuk mencegah penimpaan data simultan (race condition).
